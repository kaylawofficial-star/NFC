## 1. 整体设计

### 1.1 产品定位与核心卖点

面向所有需要提升真实顾客评价和口碑的线下服务门店，帮助门店降低素材准备、店员引导和顾客写评价的成本。医疗机构是其中一个行业场景，不再是唯一客户类型。

**MVP方向：核心评价流程＋商户可选服务。** 首要目标是让真实顾客以尽可能少的操作完成自主评价：进入即有可核对草稿，不先选类型；一个主按钮串联文字复制、图片交接和平台尝试。服务天使、三类分配及其他服务按商户需要启用，不能将所有附加功能作为默认评价前置。服务天使维持已确认的默认开启，无人员时不出现；三类分配默认关闭。实际发布仍由顾客在平台完成，记录系统操作、主观确认及未知结果，不宣称一键代发。

**核心卖点：绑定即用，无门店前置准备。** 推销人员到店完成 NFC 卡片与门店绑定，门店经理现场确认绑定即开始体验，随后即可使用；不再要求门店上传素材、准备300条内容、提供视频、添加医生或服务人员、注册后台或另点开通。

“无前置条件”指没有额外门店准备步骤，仍须正确识别门店与目标平台。本店缺少图片或某平台没有可执行路径时，系统如实显示能力范围，不能以其他门店实拍冒充本店图片，也不能承诺客观上不存在的图片或视频能力。

商业推广路径：平台及推销侧整理参考素材 → 到店绑定 → 店员免费体验 → 向老板展示可验证的工具使用效果 → 门店充值。拜访前准备属于供应侧运营工作，不是门店必须完成的事项，也不得成为每家门店依赖人工整理后才能使用的隐藏门槛。

### 1.2 用户与业务对象

| 对象/角色 | 职责与边界 |
|---|---|
| 门店 | 内容池、平台门店入口、免费及套餐次数、订单与贡献统计的基本单位；同一品牌不同门店独立核算 |
| 顾客 | 无需账号或手机号；选草稿、核对修改、删换补图、复制保存，自行在本人平台账号发布 |
| 门店经理 | 现场确认首次绑定及开始体验，决定是否使用服务天使；服务天使默认开启 |
| 服务天使/服务人员 | 记录店员引导顾客使用工具的贡献，不代表已发布，不自动成为素材所有者 |
| 素材归属人 | 医生或其他服务人员，可选；素材可仅归属门店，不强制每店绑定医生 |
| 推销人员 | 到店识别门店、绑定卡片并演示，测试操作与正式顾客使用区分 |
| 平台运营 | 内容整理、来源管理、分类复核、规则与平台入口维护、异常处理 |
| 财务及内部管理员 | 充值核账、账本更正、物料管理和内部权限；服务天使公共入口不能取得这些权限 |

### 1.3 顾客主流程

扫码/NFC进入 → 核对当前门店及平台 → 自动展示草稿 → 顾客核对、可改文/删换补图 → 点击主按钮 → 复制完整文字 → 全部图片批量保存/系统交接（最多等待30秒）→ 服务天使必选弹出页（满足条件时）→ 尝试打开对应平台 → 顾客自行完成评价发布。无图跳过图片步骤，不显示顾客三选一或主动切类入口；具体规则见POOL-007—009。

服务天使默认开启；关闭或无可用人员时不出现。开启且有人员，当天同店同设备尚无有效选择时，图片交接结束后弹出必选页，无关闭/跳过按钮，点击人员直接发起平台尝试；同日跨平台沿用选择，次日重新选择，已选人员失效按ANG-003重新判断。公共服务天使管理入口仍无需门店权限验证或登录。

不新增独立准备页。新评价主流程要求先成功复制完整文字，失败停留重试/手动复制后继续；图片保存失败、取消或超时均可继续，不强制顾客确认已保存。执行中的主按钮禁用、使用唯一流程ID，结果允许继续/重试时恢复，不在必选人员页未完成时开放绕过入口。系统手势过期时允许再点原按钮继续。无文字的收藏等独立任务不适用复制前置。顾客可离开或放弃，不预选好评、不限制真实负面修改、不代发。

### 1.4.2 入口和端侧分工

门店首页、直接素材链接、物料绑定入口分别标识；H5二维码与微信小程序码不可混称。H5负责本店内容展示编辑及经验证的复制、文件交接、平台尝试；小程序承接已报告接入的支付及相关业务入口，具体可开放页面以回执为准，不因此要求匿名顾客先登录。

微信内置浏览器无法完成原生交接时，提供该环境实测通过的系统浏览器打开指引。跳转保留门店、可选医生、其他业务参数及hash；来源参数仅记录来源，不能改变门店授权。不得假设微信与系统浏览器共享Cookie、设备令牌或草稿；若需带回本店，用受控上下文令牌而非URL明文顾客正文，跨端草稿迁移不是现有承诺。支付返回按订单恢复到原受益门店，不依赖返回页证明到账。

### 1.5 产品模块与数据流

系统由触达绑定、参考素材与交付素材、草稿内容池、顾客编辑交付、平台适配、使用账本、服务天使、充值及物料管理组成。

门店绑定生成稳定门店ID及绑定版本 → 系统自动组织该店候选 → 分配草稿并记录展示 → 会话内编辑和素材交付 → 跳转服务按门店/设备/平台/日期去重 → 同一有效使用消耗一个次数并关联至多一份人员贡献 → 后续仅按真实证据记录平台结果。

内容分配、收费、贡献、平台发布分别是独立事件；不能用其中任意一个代替其他事件。
