# 评价文案与AI图片验收标准

- 日期：2026-10-20（北京时间）。标准版本：1.0。
- 状态：用户已逐项确认设计；本文供书面复核。未执行素材批量质检或生产切换。
- 需求主体：[通用版PRD](通用版PRD.md)；本文承接SRC-002、004、005、007、008、011及新增SRC-012的验收细则。

## 1. 目标与适用范围

为碰碰贴提供给顾客核对、编辑和自主发布的评价文案、本店AI处理图片及图文组合，建立可执行的准入标准。采用“底线检查＋质量评分＋正反例”，不以生成成功、素材数量或顾客尚未修改作为质量通过证据。

本轮采用预生成模式：AI根据门店资料和参考评论准备内容，不以先取得当前顾客的体验输入为前提。允许可核实的门店信息及温和的主观评价草稿，例如“环境舒适、服务热情”，供顾客核对修改。这些主观草稿不是已核实的当前顾客感受；不得移植历史评论中的具体消费、价格、人员、时间、过程或效果。

图片采用C1范围：允许重构视角、构图和光线，实际装修、空间布局、设施与服务内容不变。新视角露出的区域须有本店其他实拍佐证，不凭模型补全认定真实。不新增不存在的人物或服务活动，不把变体称为新增实拍。

本标准适用于平台提供的公共候选内容及其交付组合。顾客会话内自行改文、删补图继续按主PRD处理，不因此新增人工审核前置，也不回流公共候选池。原有来源状态、隐私、停用传播、必要AI标识、格式及平台限制继续适用；不新增硬字数或最低分辨率承诺。

## 2. 已比较的验收方案

| 方案 | 优点 | 代价与限制 |
|---|---|---|
| 底线检查＋质量评分＋正反例（已选） | 严重问题直接阻断，普通质量可量化，判例帮助统一尺度 | 需要保留评分理由并校准样例 |
| 全部通过／不通过清单 | 简单、容易执行 | 难表达自然度、美观和信息量的差别 |
| 人工整体评审 | 灵活 | 审核者之间容易不一致，批量验收成本高 |

## 3. 一票否决与待核实

以下任一问题出现即退回，不进入加权评分放行，其他项目高分不能抵消。

| 对象 | 必须退回的问题 | 可接受边界 |
|---|---|---|
| 文案事实 | 串店、信息错误；无依据写具体消费、价格、人员、时间、过程或效果 | 可写已核实的本店信息 |
| 主观评价 | 虚构具体经历，如“医生反复给我讲解”“做完完全不疼” | 可写“环境舒适、服务热情”等温和感受草稿，供顾客核对修改 |
| 文案完整性 | 语句残缺、明显语病、占位符、生成指令残留、整段照搬来源 | 表达完整，可直接阅读和编辑 |
| 图片真实性 | 改大空间、改变装修布局、增删实际设施；虚构人物或服务活动 | 重构视角、构图、光线；新增可见区域有本店实拍佐证 |
| 图片质量 | 明显变形、物体穿帮、招牌错字、主体模糊，或泄露人脸、病历等隐私 | 保留真实细节，隐私妥善处理 |
| 图文组合 | 图文事实矛盾，混入其他门店图片，用近似图凑张数 | 图文不矛盾，同组图片展示不同场景或内容 |

证据不足以判断真实性时，标记“待核实”，补齐来源或实拍佐证后重新检查，不凭视觉观感放行。已经确认违反底线的内容标为“退回”，不能用待核实掩盖已知问题。

“服务热情”这一类不绑定具体事件的温和感受按草稿边界处理；“某位医生给我详细讲解”等带具体人员或事件的表达须有当前顾客依据，不能以历史评论替代。

## 4. 质量评分

文案、单张图片和实际交付组合分别评分。纯文字不评图片或图文组合；有图时，文案、每一张图及组合均须通过，不能在对象之间取平均。

| 验收对象 | 评分项 | 权重 |
|---|---|---|
| 文案 | 自然流畅 | 30 |
| 文案 | 内容具体且有信息量 | 30 |
| 文案 | 表达差异性 | 25 |
| 文案 | 阅读与平台适配 | 15 |
| 单张图片 | 真实自然感 | 35 |
| 单张图片 | 清晰度与细节 | 30 |
| 单张图片 | 构图 | 25 |
| 单张图片 | 曝光与色彩 | 10 |
| 图文组合 | 内容匹配 | 40 |
| 图文组合 | 场景多样性 | 35 |
| 图文组合 | 整体协调性 | 25 |

每个评分项按整数1—5分评定：

| 分值 | 统一尺度 |
|---|---|
| 5 | 可直接使用，无明显问题 |
| 4 | 有轻微不足，不影响使用 |
| 3 | 有明显不足，需要修改 |
| 2 | 问题较多，需要大幅修改 |
| 1 | 基本不可用，需要重新生成 |

总分＝各项（权重×该项分值÷5）之和。通过须同时满足：无一票否决问题、无待核实事项、总分≥80、每项均≥4。各项最低4分已能保证总分至少80；仍保留总分便于质量比较，不据总分豁免单项门槛。

单图组合不评场景多样性：总分＝（40×内容匹配分÷5＋25×整体协调分÷5）÷65×100。按未四舍五入的值判断门槛，显示可保留一位小数。

### 4.1 文案评分尺度

- 不靠字数拿分。扼要稿表达清楚即可；详细稿应增加有效信息，重复夸赞、堆形容词不算丰富。沿用主PRD“按信息维度区分扼要和详尽”的规则。
- 差异性对照同店已有可用文案及本批候选判断，记录对照稿ID与理由。只改标点、换同义词或调语序，不算充分差异；不把配图变化计为新文案。
- 自然流畅检查用词、语气、衔接与重复；明显语病已属于底线，评分处理的是未触底但影响自然度的表达。
- 阅读与平台适配检查全文完整、排版可读、无多余内部说明，并符合已核实的目标平台限制与必要标识规则；不自行杜撰平台字数上限。

### 4.2 图片与组合评分尺度

- 自然可信优先，保留适量真实纹理。过度磨皮、锐化、饱和或明显渲染感扣分；明显变形、事实变化及隐私泄露直接按底线处理。
- 清晰度与细节以最终交付文件判断，检查主体、边缘和文字，不以预览缩略图代替。
- 重构视角必须先通过实拍佐证核对，再评构图好坏；不能靠自然感高分抵消无依据区域。
- 内容匹配区分“不矛盾”和“有呼应”：没有矛盾但图片未呼应文字重点，可以因匹配不足需要修改；事实矛盾直接退回。
- 场景多样性看画面内容，单纯裁剪、改色或对同一场景换视角不能充作多个不同场景。近似图凑数直接退回；选择范围和张数继续按SRC-005及POOL规则。
- 整体协调检查同组图片色调、亮度和呈现是否协调，不要求不同场景机械使用同一种滤镜。

## 5. 正反例

以下均为假设示例，门店特征须有资料或实拍佐证，不能直接当作任何门店的可交付内容。

| 验收项 | 4—5分：可使用 | 3分及以下：须修改 | 一票否决：退回 |
|---|---|---|---|
| 文案自然度 | “店里以木色为主，搭配暖光，整体感觉挺舒服。” | “环境非常好，氛围非常好，各方面都非常好。”空泛、重复 | 提示词、占位符或语句残缺 |
| 文案信息量 | 详细稿描述已核实的装修、等候区等特征，信息不重复 | 详细稿反复说“很好、不错、值得推荐”，没有新增信息 | 编造价格、消费过程或效果 |
| 文案差异性 | 相比已有稿，描述重点和表达结构均有变化 | 仅把“环境舒适”改为“环境舒服”，其余基本一致 | 整段照搬来源评论 |
| 图片自然感 | 光影、材质、透视自然，保留真实纹理 | 表面过度光滑、色彩过艳，明显像效果图 | 墙体、家具变形，招牌文字错误 |
| 图片视角重构 | 新视角中的布局与设施均有本店实拍佐证 | 事实未变，但构图失衡或主体不突出 | 确认虚构新露出区域，或把空间变大；仅缺实拍依据时待核实 |
| 图文组合 | 木色装修文字与图片对应，多图展示不同内容 | 无事实矛盾，但图片未呼应文字重点，或色调明显不协调 | 图文事实矛盾、串店或近似图凑数 |

单个维度的合格例不代表完整对象已通过，仍须检查其余项目。

图片实物样例尚未校准。项目现有页面截图不能替代门店原图与处理图的对照。实物判例应以“本店原图＋新视角佐证图（适用时）＋AI处理图”组成，并附问题位置、分项分数和结论。未完成实物校准不影响本规则成文，但不能宣称真实图片已验收通过。

## 6. 验收流程与模块职责

| 环节 | 职责与输入 | 输出与依赖 |
|---|---|---|
| 来源与证据整理 | 收集门店事实、文本参考、本店原图及视角佐证，保持原始内容与整理结论分离 | 可追溯来源；依赖主PRD的来源分类及状态 |
| AI初检 | 依据当前标准定位底线问题、缺失证据，提供分项评分和理由 | 初检建议，不自动等同通过 |
| 平台人工终审 | 逐条核对文案、逐张核对图片，再审核实际图文组合 | 最终结论、评分、证据和审核人；审核由平台承担 |
| 可用集合准入 | 仅接纳终审通过的对应版本 | 可交付内容；不得拿新组合复用旧组合的通过结论 |
| 变更与停用 | 内容或来源变化时定位受影响文案、图片和组合 | 暂停关联交付并复核，保持不相关内容可用 |

首版采用AI初检＋平台侧人工终审，不采用抽检替代逐项审核。后续是否改为抽检，另根据实际漏检情况决定。此运营工作不增加门店上传、准备或培训步骤；未审就绪导致首稿不可用时，仍按主PRD记录绑定即用失败，不以审核要求豁免。

组合审核针对最终选定的文图及版本；随机换图生成的新组合须有相应审核结论才能交付。若尚无已审核组合，记为未就绪，不把单项合格推断为组合合格。具体审核工具与调度实现不在本轮范围。

## 7. 结论、修改与失效处理

| 结论 | 条件 | 后续 |
|---|---|---|
| 通过 | 底线及证据检查通过，评分全部满足门槛 | 对应版本可进入可用集合 |
| 待修改 | 未触底线且证据足够，但总分或单项未达标 | 修改后重验，不交付 |
| 待核实 | 尚无充分依据判断真实性等必要事项 | 补齐证据后重验，不交付 |
| 退回 | 已确认触犯任一底线 | 记录原因，修正或重生成后重验，不交付 |

同一对象同时存在已知底线问题和证据缺失时，结论为退回，并一并记录缺失证据。AI建议与人工判断不一致时保留两者及最终理由，以人工终审结论为准，不覆盖初检记录。

改文后重验文案及关联组合；改图后重验图片及关联组合。来源失效、原图停用、门店装修或设施变化时，关联内容暂停使用并复核；沿用主PRD的旧链接及待下载包重查规则。不能为满足约300条或规定图数降低门槛。

## 8. 验收记录

每项记录内容ID、对象类型、门店ID、来源ID/版本、生成版本、标准版本、适用平台、各项分数与理由、总分、底线检查结果、最终结论、问题位置、退回/修改原因、审核人及北京时间审核时间。

图片另关联原图ID/版本、新视角佐证图ID/版本及处理图版本；差异性另记录对照文案ID；组合另记录文案版本和有序图片版本列表。无图不创建图片或组合评分，用“不适用”区分于未审核。记录按主PRD的来源、权限及必要审计要求管理，不把顾客私有改文或补图写入公共审核记录。

## 9. 规则验证场景

本文为文档规格，以下是正式执行时须覆盖的验收场景，不代表已经用真实素材实测通过。

| 场景 | 预期 |
|---|---|
| 无当前顾客输入，出现“环境舒适、服务热情” | 允许作为温和感受草稿继续检查，不自动认定是顾客证言 |
| 从历史评论移植“今天花128元洗牙，全程不疼” | 退回 |
| 图片重构自然，但新露出区域缺少本店实拍依据 | 待核实，不交付；已确认虚构则退回 |
| 一项3分、其余5分，总分超过80 | 待修改，不能靠总分放行 |
| 所有适用项4分 | 总分80，其他检查均通过时通过 |
| 单图组合内容匹配4、协调性5 | 按65权重归一，总分约87.7，满足评分门槛 |
| 文案与每张图片单项通过，新组合未终审 | 组合未就绪，不交付 |
| 多张由同场景裁剪改色的图片组成 | 不按不同场景计数；凑图则退回 |
| 修改已通过图或来源被停用 | 关联版本与组合不得继续沿用旧通过状态 |
| 为补足图片数量加入未核实图 | 不通过，按供给异常处理 |

## 10. 本轮交付边界

本轮交付验收标准及主PRD同步，未生成门店图片、未搭建审核系统、未调用付费模型、未配置生产审核或改变线上素材。可视化辅助已获同意；本轮没有可用的真实原图与处理图对照，因此未以页面截图冒充图片效果判例。

本标准明确覆盖旧SRC-007禁止预生成温和主观评价的限制；保留不虚构具体顾客经历的底线。SRC-011明确允许有实拍佐证的视角重构，保留门店实际事实不变。2026-10-19流程设计作为历史决策记录保留，当前需求以主PRD及本文所列细则为准。
