# 星满客 MVP 四部分流程细化设计

- 日期：2026-10-19（北京时间）。
- 状态：用户已逐项确认设计并授权整理成文；本文供书面复核，尚未开发、部署或真机验收。
- 主规格：[通用版PRD V2.2](通用版PRD.md)。需求主体统一维护在主PRD，本文是本次流程决策及验收场景的阅读稿；后续变更优先同步主PRD，避免形成并行规则。
- 本轮交付仅为产品文档，保留原口腔PRD与历史版本；没有生成图像、执行付费模型调用、配置线上销售提醒或代顾客发布。

## 1. MVP边界

采用“核心评价流程＋商户可选服务”。核心目标是减少真实顾客从取得草稿到在目标平台自主评价的操作；门店绑定即用，不以先上传素材、配置人员或培训为前提。

比较过三种方向：核心评价加可选服务、综合服务首页、完整配置后使用。用户选择第一种；综合服务首页增加顾客判断，完整配置增加销售及开通成本，因此保留辅助能力但不将其统一置于评价前。

默认提供详细文字＋1—5张图片，不让顾客先选三种类型。三类分配默认不开启；服务天使可选但沿用默认开启，无可用人员时不出现。Wi-Fi、加微信、关注等保留在相应独立入口/阶段，不进入必经评价链路。

“一键”是主按钮编排目标，操作系统文件菜单、手动复制补救和失效手势续接仍可能需要额外点击。须分别测网页、系统及目标App中的操作，不承诺自动填入第三方或代发。

## 2. 评论内容与日分配

| 商户模式 | 顾客初始内容 | 分配方式 |
|---|---|---|
| 默认 | 详细文字＋1—5张图 | 系统直接展示，无前置类型选择 |
| 开启三类：扼要无图 | 扼要文字、0图 | 20% |
| 开启三类：扼要少图 | 扼要文字、1—3图 | 40% |
| 开启三类：详尽多图 | 详细文字、4—5图 | 40% |

三类概率适用于每个设备当天首次类型抽取，不要求全店每天使用总量恰好达到比例。记录维度为门店＋可识别设备＋北京时间自然日＋模式配置版本，不按平台另抽。

- 同日刷新、重进、跨平台及“换一篇”均保持类型；换篇只在该类型内换母稿和配图，无顾客主动切类入口。
- 刷新可以取得新母稿，但顾客私有改文/补图不恢复；类型元数据独立存储，不与私有草稿一并清除。
- 具体母稿仍全店轮换、展示即消耗。同一类型不等于同一草稿，跨平台适配及默认模式复用详细正文不能重置母稿名额。
- 商户开/关三类后下次进入或刷新立即生效，覆盖用户此前短暂选A的答复，以最终B为准；当前已编辑页面不热切。配置递增版本，新版本按模式重新分配，当天计次和人员选择不重置。
- 新自然日首次进入重抽类型；午夜不强制替换仍在编辑的草稿，出站按当日人员及计次判断。

默认配图先筛质量、事实一致性和场景差异，再在可组成的1—5张范围随机决定张数；三类同样按各自张数范围组成，不以重复/近似画面凑数。顾客可自主改文及将图片改至0—5张，不强制重分类。

后台以本店真实照片生成图片变体，保持真实环境、设施和服务内容不变；不用文字描述制造全新门店场景、不以其他门店图片交付。记录原图/变体/模型及任务版本，检查后入候选，变体不标新增实拍，继承原图失效约束。单纯裁剪/改色不算不同场景。

持续变体供给是正常产品路径；生成失败、没有真实原图或质检不合格仍须如实记录，不将“AI可以生成”当作必然足图的证明。异常不静默重抽类型或虚构场景，平台侧处理，不让门店备图成为开通操作。顾客仍能使用已就绪合法内容，图片阶段按失败规则继续。

## 3. 主按钮流程

1. 顾客核对草稿并点击主按钮。建立唯一流程ID，固定当前正文/图片版本，主按钮进入禁用状态。
2. 复制完整评价文字，不带风格名、占位或光标。失败留原页重试或手动复制，不重新生成、不继续保存/选人/跳转；手动复制由顾客主动确认继续，不能伪记API成功。
3. 复制成功后，一次批量发起全部配图保存/系统文件交接；无图直接跳过。
4. 等整批均返回，或从图片阶段开始累计30秒到期。逐图保留实际可得的成功、失败、取消、未完成及请求已发起但保存未知；系统只回整批结果时不制造逐图相册成功证据。
5. 图片失败、取消、部分失败或超时都允许继续。之后才判断服务天使，不在首图完成时提前弹出；有系统菜单时不试图强制关闭系统UI，恢复网页后的继续沿用同流程。
6. 若需服务天使则必选，无需时直接发起已验证目标平台尝试。浏览器手势失效需用户再点原继续动作，不异步重放手势。
7. 实际attempted后按门店/设备/平台/自然日去重扣一次、关联至多一份贡献。复制、保存、选人或仅accepted不收费。

执行期间不接受重复主按钮流程；结束/可恢复失败/批量超时后按当前状态恢复继续动作，不能绕过未完成的人员必选。锁与幂等请求共同防重复，不仅依赖按钮变灰。

图片补保存留在仍有效的页面，按未完成项重试，不再生成草稿或重复计次。超时后的迟到回执仅更新原文件状态，不重复弹页/出站。关页或刷新后仍执行主PRD的私有内容清理，不承诺恢复历史文件。

此设计明确覆盖V2.1“评价直接打开不要求复制”的交互；计次事件仍为平台尝试，不改成复制成功即计费。收藏等无正文任务不硬套复制前置。

## 4. 服务天使状态与贡献

主页公共入口可添加/管理本店人员，无门店权限核验或登录前置；不能借此获得套餐财务、素材管理、绑卡或商户模式配置权。服务天使默认开启，门店经理可关闭。

| 图片阶段之后的状态 | 行为 |
|---|---|
| 已关闭 | 不弹出，进入平台尝试 |
| 已开启但无可用人员 | 不弹出，进入平台尝试，无人员贡献 |
| 已开启、有人员、当日无有效选择 | 弹出必选页，无关闭/跳过按钮；点击人员直接进入平台尝试 |
| 同日同店同设备已有仍有效选择 | 不再弹出；跨平台也沿用 |
| 新自然日首次出站 | 重新选择，当日后续沿用 |
| 当日已选人员被停用/删除 | 有其他可用人员重新必选；无人直接跳转；历史贡献不转移 |

“不提供关闭按钮”包括产品不以遮罩或自有返回按钮绕过必选；顾客仍能通过浏览器/系统离开，离开不等于已选择或已使用，不对设备进行锁定。

人员选择按门店＋设备＋日期独立保存，和按平台去重的计次主键分离。每天首次选定后沿用，选择本身不产生贡献；未发起平台尝试不收费。点击时重验人员/开关状态，人员失效重新判断，不重做已结束图片批次。

有效使用在发生时锁定归属，免费与套餐次数同等贡献，素材归属独立。跨平台新有效使用归同一当天有效人员；重复同平台不增加贡献。历史无归属或旧人员贡献不由后来的人员选择补抢或转移；更正走主PRD账本规则。

排名同时提供本店自然月榜和自然季度榜，以北京时间起止、有效使用发生时间归期。仅本店人员，无跨店榜；同分并列名次1、1、3；测试、重复及撤销不计，免费/付费均计。重命名/停用保留历史，更正可复算原期，不默认奖励或分润。

## 5. 到店推广与跟进

主路径：销售登录并准备可绑定物料 → 到店核对本店 → 经理现场确认绑定 → 即时启动66次/72小时及30天优惠T0 → 测试演示完整主流程 → 当场向老板展示效果和五档套餐 → 当场购买或继续免费 → 系统提醒销售人工跟进。

绑定完成即开通，演示完成不是第二次开通条件。测试演示不消耗正式内容轮换、免费/套餐次数及贡献；不制造虚假“已发布”。没有人员不强制先添加，店铺无需上传、配置评论或培训才能体验。

销售展示实际工具使用效果，不能把复制/下载/跳转称为已新增好评；套餐按原BILL规则下单/到账，首次T0及免费截止不因购买或补发物料重置。

| 提醒触发 | 提醒对象与内容 |
|---|---|
| 开通约20小时 | 负责销售；真实使用/剩余次数及首24小时28%赠次窗口 |
| 免费期剩约12小时（约开通60小时） | 负责销售；剩余时间、体验结果及当时实际优惠，不能仍称首日28% |
| 免费次数剩余≤10 | 负责销售；首次达到阈值提醒用量即将耗尽 |

已购买、已处理或同类短时间重复触发合并抑制；延迟通知以当前实际权益和优惠为准，不重复催办。系统仅提醒销售，销售决定联系时机并人工记录结果，不自动向老板发短信/微信。负责销售默认取首次绑定销售，内部交接留记录；具体提醒呈现渠道属实现选择，不在本轮开通真实通知。

## 6. 数据及模块边界

| 模块/记录 | 职责及依赖 |
|---|---|
| 商户配置 | 服务天使开关及三类模式/版本；不与匿名人员管理共用写权限 |
| 每日类型记录 | 门店/设备/日期/配置版本及类型，不含顾客私有正文；依赖可识别设备令牌 |
| 草稿分配 | 全店母稿轮次、预留/展示；依赖当前类型与合法来源，不用日类型替代轮换 |
| 交接流程 | 唯一流程ID、正文/文件版本、阶段/结果；依赖真实浏览器能力，不推断App成功 |
| 当日人员记录 | 门店/设备/日期/所选人员ID，不按平台拆开；失效重验 |
| 有效使用/贡献 | 按门店/设备/平台/日期去重并锁定发生时归属；依赖attempted、有效次数及当前绑定 |
| 图像变体 | 本店真实原图、生成/质量/来源版本；不处理顾客私有补图入候选 |
| 销售提醒 | T0/有效使用/免费余次/订单状态与负责销售；不操作顾客主流程 |

匿名H5设备令牌不保证跨浏览器的物理设备唯一；换浏览器、清缓存可能识别为新设备，不能因此宣传绝对去重。私有改文/补图不回流、会话失效清理、支付及旧权益迁移继续按主PRD执行。

## 7. 验收场景与交付边界

| 主题 | 必验场景 |
|---|---|
| 默认MVP | 新店无人员/无配置直接详细文字＋1—5图；主按钮执行不先问类型 |
| 随机稳定 | 用足量独立首次抽样核对20/40/40实现与随机机制，不要求短样本恰等比例；同日刷新/换篇/跨平台保持、次日重抽 |
| 模式切换 | 开/关后下次进入立刻生效、当前页不强切；配置版本/母稿轮次/计费/人员互不误重置 |
| 图片变体 | 原图来源、事实不变、质量/近似检查、撤权传播；不以AI生成宣称无限不同场景 |
| 复制与图片 | API失败/手动确认、0/1/5图、整批取消/部分失败、30秒超时、未知/迟到结果、单项补保存 |
| 系统能力 | iOS/Android/鸿蒙/微信内置分别实测批量及新手势需求，不把Files交接当相册保存或App自动带入 |
| 服务天使 | 必选无关闭跳过、点人直跳、日复用跨平台、次日重选、名单变化及关闭/无人分支、浏览器离开不计次 |
| 账与榜 | 每日平台去重、免费贡献、月/季边界、并列1、1、3、更正和停用历史不转移 |
| 推广 | 绑定T0、测试演示免耗、当场可买可不买、三时点提醒、订单/已处理抑制及销售人工处理 |

四部分均为产品设计确认；正式实施需拆分内容供给、主按钮编排、服务天使及销售运营等任务，针对真实平台和系统能力做验证，不能把本文件当作已上线说明。本轮不自动开始实施计划、代码开发、部署或push。
