# 服务商户行业与场景验收目录

- 日期：2026-10-22（北京时间）。目录版本：1.0，适用[评价图文验收标准1.2](../superpowers/specs/2026-10-20-review-content-acceptance-design.md)。
- 产品对象：在点评、评分或其他口碑平台展示并接受顾客评价的服务商户，以及提供到店、上门或线上服务的经营者。餐饮、医疗、按摩只是示例，不限定行业范围。
- 本目录用于选择验收规则，不代表所有行业已接入、所有平台支持全部行业，也不承诺评分或好评结果。

## 1. 使用规则

按实际经营项目选择行业编号，再填写细分业态、本店定位与来源依据。目录提供可选评价维度，不能将其自动写成门店事实或顾客经历。项目、收费、资质、人员、设施、服务时段与结果均按本店资料核实；不能根据类别推断“全天营业”“免费停车”“持证专家”等。

“适用重点”表示有对应资料时可以讨论的主题，涉及顾客具体感受、过程及结果时仍须有当前顾客输入。正文预生成仅沿用标准允许的温和主观草稿边界，例如不能因为餐饮关注口味就生成“我吃着很鲜”，不能因为维修关注交付就生成“当天修好”。

图片一律遵守本店真实来源、C1事实不变、隐私与必要标识要求。表中可用图片须是本店实际场景或有据业务对象，不能照表生成不存在的项目、客户、场地或活动。作品、案例和展示样板须分清，不能把样板当作本店交付案例，不能把他人作品或客户成果当作当前顾客成果。

目录中“偏离”按主标准判定：事实写错退回；语气或重心明显不适配待修改；所需依据缺失待核实。单个词不自动触发结论。

## 4. 混合业态与分类边界

1. 一店可关联多个编号，记录主营及实际兼营业务；每条文案和组合标本次实际服务主题，不把所有业务混写。业务主次不明保留未知，不据名称猜测。
2. 咖啡＋手作可用S02＋S31；酒店＋餐厅＋SPA可用S03＋S01＋S06；宠物洗护＋诊疗可用S19＋S20。兼营业务须分别有依据，不能因同店有一个项目推定全部具备。
3. 分类交叉时按评价对象选择：儿童摄影为S17并补S15隐私与年龄场景；烘焙体验为S31，售卖糕点为S02；礼服租赁可按S18，婚纱拍摄为S17。
4. 推拿、康复、产后、皮肤管理、验光等名称不能单独证明属于医疗或非医疗。核对经营主体、实际项目及必要资质；证据不足时暂停相应诊疗或功效表述，不凭外观归类。
5. 出行、房产、专业服务等非传统到店业务，用实际服务范围和交付方式建立档案，不要求套“店里环境好”。上门或线上服务的办公图不能冒充顾客实际服务现场。
6. 目录外新业态可扩展：先记录实际服务对象、项目、交付方式、可核实评价维度、语气边界、图片对象和不适用表达，再按同一标准审核。不强制归入相近但错误的类别。目录新增编号和版本，不调整旧编号含义。

这32类是覆盖常见服务商户的运营分类，不是对平台类目或所有经济行业的穷尽清单。细分业态持续扩展，产品范围不被目录封闭；目录以外也不能只用通用夸赞替代场景规则。
