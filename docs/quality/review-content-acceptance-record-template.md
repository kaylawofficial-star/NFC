# 评价图文审核记录模板

适用[验收标准1.0](../superpowers/specs/2026-10-20-review-content-acceptance-design.md)。复制本模板为每个文案、单图或组合建立独立记录；空白仅表示待填写，不代表通过。

|---|---|

| 内容ID／版本 | |
| 门店ID／名称 | |

| 原图ID／版本（图片适用） | |
| 新视角佐证图ID／版本及佐证区域（适用时） | |
| 场景／近似组（图片适用） | |
| 同店对照文案ID（文案适用） | |
| 文案ID／版本（组合适用） | |

真实素材附可访问的来源与文件定位。假设判例、测试演练单独标明，不混入真实准入清单。不适用字段填“不适用”；需要但尚未取得的依据填“缺失”并记录原因。

## 2. 底线与证据检查

逐项填写“无问题／有问题／待核实／不适用”，附证据或具体问题位置。

| 检查项 | 结果 | 依据／问题位置 |
|---|---|---|
| 门店及来源归属正确 | | |
| 无编造具体消费、价格、人员、时间、过程或效果 | | |
| 主观感受未绑定虚构具体经历 | | |
| 无残缺、明显语病、占位符、指令残留或整段照搬 | | |
| 图片装修、布局、空间、设施、人物与服务活动真实 | | |
| 重构视角新增可见区域有本店实拍佐证 | | |
| 无明显变形、穿帮、招牌错字或主体模糊 | | |
| 无隐私泄露，来源状态允许交付 | | |
| 图文事实不矛盾，无串店或近似图凑数 | | |
| 最终交付格式、适用平台限制及必要标识已核对 | | |

已知触底线：退回；无已知底线问题但证据不足：待核实。均不交付，评分可记“未评分”，不能填0分后求平均。

## 3. 分项评分

只填写当前对象类型对应的表格，其他表格标“不适用”。每项整数1—5分，记录理由。AI建议和人工终审各自保留，未执行AI初检写“未执行”。

| 文案评分项 | 权重 | AI建议 | 人工终审分 | 理由／对照证据 |
|---|---|---|---|---|
| 自然流畅 | 30 | | | |
| 内容具体且有信息量 | 30 | | | |
| 表达差异性 | 25 | | | |
| 阅读与平台适配 | 15 | | | |

| 单图评分项 | 权重 | AI建议 | 人工终审分 | 理由／问题区域 |
|---|---|---|---|---|
| 真实自然感 | 35 | | | |
| 清晰度与细节 | 30 | | | |
| 构图 | 25 | | | |
| 曝光与色彩 | 10 | | | |

| 组合评分项 | 权重 | AI建议 | 人工终审分 | 理由／关联对象 |
|---|---|---|---|---|
| 内容匹配 | 40 | | | |
| 场景多样性（单图不适用） | 35 | | | |
| 整体协调性 | 25 | | | |

普通对象总分＝Σ（权重×分值÷5）。单图组合总分＝（40×匹配分÷5＋25×协调分÷5）÷65×100。无底线问题、无待核实事项、总分≥80且每适用项≥4才满足通过条件；有图组合还需关联文案及每张图片的对应版本均已通过。

未完成审核时填写“审核中”，不得预填“通过”。修改后以新版本建立记录并关联本记录；保留原始结论。顾客私有改文及补图不填写到公共审核记录。
