真实素材附可访问的来源与文件定位。假设判例、测试演练单独标明，不混入真实准入清单。不适用字段填“不适用”；需要但尚未取得的依据填“缺失”并记录原因。

档案未知项填“未知”，不能凭装修推断客群、价格档次或项目。当前表达依赖未知定位才成立时待核实，不依赖该定位的有据内容可继续审核。旧记录保留原标准版本，不能只改版本号声称已完成新标准复核。

未完成审核时填写“审核中”，不得预填“通过”。修改后以新版本建立记录并关联本记录；保留原始结论。顾客私有改文及补图不填写到公共审核记录。

行业、业态或项目写错直接退回；语气或重点明显不适配，相关文案“自然流畅”或“内容具体且有信息量”项≤3分，记待修改；缺少判断所需依据记待核实。不能仅凭一个关键词认定偏离。

单项通过不等于批次整体准入，交付前检查适用批次结论及组合审核。评分权重和门槛不变。

## 5. 批次场景与风格复核记录

同店＋同类文案池＋同一生成规则版本单独复核，按需复制本节。不以批次平均分替代单项审核。

| 字段 | 填写值 |
|---|---|
| 批次ID／门店ID／文案池／生成规则版本 | |
| 标准版本／行业目录版本／行业编号／场景档案ID及版本 | |
| 本批文案ID及版本／条数 | |
| 同池同规则版本已有文案的累计对照范围 | |
| 关联实际组合ID及版本 | |
| 主要主题分布及对应文案ID | |
| 是否全部同主题且缺少实质变化／例句 | |
| 是否只有同义替换等／对照文案ID | |
| 是否整批缺少行业及本店信息／例句 | |
| 单条、图片与实际组合是否完成相应审核 | |
| 批次结论 | |
| 调整原因／移出内容／后续复核批次ID | |
| 实际准入内容与组合范围 | |
| 复核人／复核时间（北京时间） | |

批次结论填写“复核中／通过／待调整／待核实／单条批次，多样性待累计”。三项风格问题任一成立则待调整，不整批放行；必要依据不足则待核实。仅一条时允许依单条及适用组合审核准入，新增同池同规则版本内容时累计复核，不通过拆批规避多样性检查。调整集合后记录新旧批次关联，不能仅更换ID。

没有主题比例门槛；不要求每条写行业术语，也不为丰富主题编造事实。单条结论保留，批次未通过不能据此自动整体准入。
